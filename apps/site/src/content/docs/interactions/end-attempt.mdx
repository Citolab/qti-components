**[3.2.21 End Attempt Interaction](https://www.imsglobal.org/spec/qti/v3p0/impl#h.b3g8rgbtuwqp)** — a special interaction that immediately ends the current attempt. Typically used to let the candidate request a hint or model solution, or to move on in an adaptive item.

Unlike the other interactions on this site, `qti-end-attempt-interaction` extends plain `LitElement`, not the shared `Interaction` base — it's a button, not a response-collecting control.

## Example

<InteractionDemo>
  <qti-end-attempt-interaction response-identifier="HINTREQUEST" title="Show hint"></qti-end-attempt-interaction>
</InteractionDemo>

```html
<qti-end-attempt-interaction response-identifier="HINTREQUEST" title="Show hint"></qti-end-attempt-interaction>
```

Clicking it dispatches an `end-attempt` event (bubbles/composed) with `detail: { responseIdentifier, countAttempt }`. On its own — outside a `qti-assessment-item`/`qti-test` context — that's all it does; the actual "end attempt" behavior (scoring, revealing feedback) is handled by whatever's listening, such as [`test-navigation`](/qti-test/navigation/) or an item's own response processing.

## Behaviour

- **Pressing it ends the attempt.** Response processing runs at once. The button's response is `true`, every other end-attempt interaction's `false`; an attempt ended any other way sets them all to `false` ([QTI info model §2.4.5](https://www.imsglobal.org/spec/qti/v3p0/info#Data_EndAttemptInteraction)).
- **It counts as an attempt unless it says `count-attempt="false"`.** QTI 3 gives `count-attempt` no default. We count when it is absent, as QTI 2.x's default `true` did and as amp-up and QTI.JS do.
- **A counted attempt uses up `max-attempts`.** In a test the default is one attempt, and the item is locked once it is used. Give a hint or "show solution" button `count-attempt="false"` when it must not cost the candidate an attempt.

## `qti-end-attempt-interaction`

| Attribute | Type | Default | Notes |
|---|---|---|---|
| `response-identifier` | `string` | — | Reported in the `end-attempt` event detail. |
| `disabled` | `boolean` (reflect) | `false` | |
| `count-attempt` | `'true' \| 'false'` | `null` (counts) | Whether pressing it counts as an attempt. Only `'false'` does not count. |
| `title` | `string` | `'end attempt'` | The button's label text. |
