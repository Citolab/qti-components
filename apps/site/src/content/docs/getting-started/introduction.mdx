`@citolab/qti-components` is a web component library for rendering [1EdTech QTI 3.0](https://www.imsglobal.org/spec/qti/v3p0) assessment items and tests. It's framework-agnostic and can be dropped into any web app that can render HTML.

## Where to go next

- **New here?** Start with the [Quick Start](/getting-started/quick-start/) — install the package and render your first item.
- **Rendering one interaction at a time?** See [Interactions](/interactions/overview/) for all 20 interaction types, each with a live example.
- **Scoring a response, showing feedback, or another specific task?** See [Guides](/guides/response-processing/).
- **Building a full, navigable test?** See [qti-test](/qti-test/overview/).
- **Wondering what a specific package does?** See the [Package Reference](/packages/).
