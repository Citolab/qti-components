# QTI Components

Web components that render and run [1EdTech QTI 3](https://www.imsglobal.org/spec/qti/v3p0) assessment
items and tests. They are framework-agnostic: put them in any page that can render HTML.

<small>Version {pkg.version}</small>

<Canvas of={Stories.Player} />

That is one `<qti-test>` over the examples assessment: the item, and previous and next. Answer a question,
go back and forth, and the test keeps your answers.

Add a `test-stamp` and the test can show a numbered link for every item. The items of this test cover most
of the interaction types, so the numbers are a quick way to see them:

## Install

```sh
npm install @citolab/qti-components
```

Importing the package registers every element it ships. The theme is loaded once, globally:

```js
import '@citolab/qti-components';
import '@citolab/qti-components/item.css';
```

That is all: no per-component imports. `test-next`, the interactions and every other element register with the package.

## The smallest test

```html
<qti-test navigate="item">
  <test-navigation>
    <test-container test-url="assessment.xml"></test-container>
    <test-prev>previous</test-prev>
    <test-next>next</test-next>
  </test-navigation>
</qti-test>
```

`test-container` loads the test XML and shows the current item. `test-prev` and `test-next` ask the test
to move. Everything else in this Storybook builds on that shape.
