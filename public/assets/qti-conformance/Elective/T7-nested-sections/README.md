# T7 - Sections

## Description

This QTI 2.2 Conformance Test Sample aims at testing the **T7 - Sections** feature. It enables vendors to
test the Delivery Engine to serve the appropriate items to the candidate depending on how **AssessmentSections**
are structured amongst the **AssessmentTest**.

## Acceptance Criteria

* The candidate will take, in order of appearance, the following Items: **Item 1-A**, **Item 1-B**, **Item 1-C**, **Item 4**, **Item 5-B**, **Item 6-B**, **Item 7-B**, **Item 8**.
