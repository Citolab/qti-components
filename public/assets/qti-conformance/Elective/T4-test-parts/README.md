# T4 - Test Parts

## Description

This QTI 2.2 Conformance Test Sample aims at testing the **T4 - Test Parts** feature. It enables vendors to
test the Delivery Engine ability to provide navigation to the candidate through **linear** and **non linear** **Test Parts**.

| T4                  |   |
|-----------------------|---|
| **Test Sample ID**        | t4-test-parts  |
| **Test Sample Title**     | T4 - Test Parts |
| **Dependencies**          | T7 - Sections |
| **Related Documentation** | [QTI ASI Model - Test Part](http://www.imsglobal.org/question/qtiv2p2p1/QTIv2p2p1-ASI-InformationModelv1p0/imsqtiv2p2p1_asi_v1p0_InfoModelv1p0.html#Root_TestPart) |

## Acceptance Criteria

* While the candidate is on **Item 1**, **Item 2**, or **Item 3**, **non linear** navigation mode is available (backward/forward navigation).
* While the candidate is on **Item 4**, **Item 5**, or **Item 6**, **linear** navigation mode is avaliable (forward navigation).
